# Giải mã chứng minh · Toán 7

Ứng dụng Vite độc lập theo dạng bài kéo thả của trang mẫu: nhập tên, chọn hoặc kéo 6 thẻ vào 5 ô lời giải, loại bỏ thẻ nhiễu, rồi nộp bài để chấm điểm trên thang 10 (2 điểm mỗi ô đúng). Bài học theo phiếu **PHT chung minh dinh ly**, về định lý tổng ba góc trong một tam giác. Thời gian làm bài là 3 phút; nhạc nền lấy từ tệp MP3 người dùng cung cấp và có thể tắt hoặc chỉnh âm lượng.

## Chạy ứng dụng

```bash
npm install
npm run dev
```

Mở địa chỉ Vite in ra trong terminal. Để tạo bản build dùng `npm run build`.

## Ghi chú

Ứng dụng tự xử lý kéo thả, chấm điểm và làm lại trong trình duyệt; không nhúng trang Liveworksheets.
